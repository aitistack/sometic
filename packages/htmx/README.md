# `@sometic/htmx`

HTMX adapters for Sometic: store bind and swap-safe button re-init via `htmx:afterSettle`.

```bash
pnpm add @sometic/htmx htmx.org
```

```ts
import { createHtmxBinderRoot, bindHtmxButton } from "@sometic/htmx";
```

Capability: **storeBind** + **button**. Docs: https://sometic.aitistack.com
