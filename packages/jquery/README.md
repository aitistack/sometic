# `@sometic/jquery`

jQuery adapters for Sometic: store bind, button bind, and `.someticButton('destroy')` cleanup.

```bash
pnpm add @sometic/jquery jquery
```

```ts
import { bindJQueryButton, registerJQueryAdapters } from "@sometic/jquery";
```

Capability: **storeBind** + **button**. Docs: https://sometic.aitistack.com
