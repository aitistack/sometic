# Button — Comparison

## vs framework-only button kits

Sometic shares one resolver across frameworks; kits usually lock you to one runtime.

## vs raw `<button>`

Use native alone for simple cases. Sometic adds loading/pressed/group/async coordination, slot styling hooks, and adapter consistency without replacing the native element.

## vs copying Radix/Ark into each app

Those excel in React (or their target). Here the engine is framework-neutral first; React/Vue are thin peers.
