# Invoice Desk kit

Private workspace package shared by the React, Vue, and Vanilla Invoice Desk example apps. Not published to npm.

**Parked:** these apps stay in the repo but are not a current docs or product surface. See `.cursor/context/examples-paused.md`.

Owns invoice types, seed users, validators, the in-memory mock API, and `createInvoiceDeskRuntime()` (`createSometicApp` + test auth + flags + drafts). Presentation lives in each example app: Tailwind in React, plain CSS in Vue, Bootstrap in Vanilla.
