# Notification center

Inbox state with read/unread, dismiss, and groups.

## When to use

Use `@sometic/notifications` when you need shared portable behavior without locking a UI kit.

## When not to use

Skip if a one-off local component is enough and you do not need cross-framework adapters.

## Usage

::: code-group

```js [JS]
import { } from "@sometic/notifications";
```

```ts [TS]
import { } from "@sometic/notifications";
```

```html [Vanilla]
<script type="module">
  import { } from "@sometic/notifications";
</script>
```

:::
