# Schema form

Descriptor-driven form over createForm.

## When to use

Use `@sometic/forms/schema-form` when you need shared portable behavior without locking a UI kit.

## When not to use

Skip if a one-off local component is enough and you do not need cross-framework adapters.

## Usage

::: code-group

```js [JS]
import { } from "@sometic/forms/schema-form";
```

```ts [TS]
import { } from "@sometic/forms/schema-form";
```

```html [Vanilla]
<script type="module">
  import { } from "@sometic/forms/schema-form";
</script>
```

:::
