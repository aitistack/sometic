# Permission matrix

Resources x actions matrix bound to auth permission checks.

## When to use

Use `@sometic/dom/permission-matrix` when you need shared portable behavior without locking a UI kit.

## When not to use

Skip if a one-off local component is enough and you do not need cross-framework adapters.

## Usage

::: code-group

```js [JS]
import { } from "@sometic/dom/permission-matrix";
```

```ts [TS]
import { } from "@sometic/dom/permission-matrix";
```

```html [Vanilla]
<script type="module">
  import { } from "@sometic/dom/permission-matrix";
</script>
```

:::
