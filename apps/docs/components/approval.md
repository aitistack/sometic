# Approval

Multi-step approval flow state machine.

## When to use

Use `@sometic/approval` when you need shared portable behavior without locking a UI kit.

## When not to use

Skip if a one-off local component is enough and you do not need cross-framework adapters.

## Usage

::: code-group

```js [JS]
import { } from "@sometic/approval";
```

```ts [TS]
import { } from "@sometic/approval";
```

```html [Vanilla]
<script type="module">
  import { } from "@sometic/approval";
</script>
```

:::
