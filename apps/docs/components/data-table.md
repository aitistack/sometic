# Data table

Table/grid state with sorting, filtering, pagination, bulk selection, URL sync, and virtualization.

## When to use

Use `@sometic/data-table` when you need shared portable behavior without locking a UI kit.

## When not to use

Skip if a one-off local component is enough and you do not need cross-framework adapters.

## Usage

::: code-group

```js [JS]
import { } from "@sometic/data-table";
```

```ts [TS]
import { } from "@sometic/data-table";
```

```html [Vanilla]
<script type="module">
  import { } from "@sometic/data-table";
</script>
```

:::
