# Upload

Upload/download queue with pluggable UploadTransport.

## When to use

Use `@sometic/upload` when you need shared portable behavior without locking a UI kit.

## When not to use

Skip if a one-off local component is enough and you do not need cross-framework adapters.

## Usage

::: code-group

```js [JS]
import { } from "@sometic/upload";
```

```ts [TS]
import { } from "@sometic/upload";
```

```html [Vanilla]
<script type="module">
  import { } from "@sometic/upload";
</script>
```

:::
