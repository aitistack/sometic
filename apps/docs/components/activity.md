# Activity

Append-only activity/audit log state.

## When to use

Use `@sometic/activity` when you need shared portable behavior without locking a UI kit.

## When not to use

Skip if a one-off local component is enough and you do not need cross-framework adapters.

## Usage

::: code-group

```js [JS]
import { } from "@sometic/activity";
```

```ts [TS]
import { } from "@sometic/activity";
```

```html [Vanilla]
<script type="module">
  import { } from "@sometic/activity";
</script>
```

:::
