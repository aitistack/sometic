================================================================================
NON-NEGOTIABLE RULES
================================================================================
- Forms bind article fields; rich text is your component feeding form state
- @sometic/drafts for autosave (omit secrets); debounce writes
- @sometic/history for intentional undo/redo command stack
- @sometic/conflict for concurrent save policy (reload vs merge prompt) — not a full CRDT suite
- Published routes set @sometic/head; drafts should be noindex if publicly reachable
- Long-term revision history beyond undo stack = your API if needed
- createAppShell for editor session; dispose; no import-time globals
- No Invoice Desk, playgrounds, telemetry, invented rich-text package
