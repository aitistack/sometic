API TRUTH (NEVER INVENT — MATCH PINNED PACKAGES)
================================================================================
Verify every symbol against the installed package `.d.ts` / README / https://sometic.dev before using it. Prefer failing loudly over optional-chaining methods that should exist.

AuthController verbs (exact):
| User intent    | Method                         |
|----------------|--------------------------------|
| Sign in        | auth.signIn({ email, password }) |
| Create account | auth.register({ email, password, displayName? }) |
| Sign out       | auth.signOut()                 |
| Session        | auth.getSession() / whenReady() / subscribe |

FORBIDDEN auth names: signUp, createAccount, login (as AuthController methods).

Head:
- Factory: createHeadController() — NEVER createHead()
- Updates: head.set(id, { title: "…" }) — NEVER head.setTitle
- DOM: in bootstrap only: applyHead(document, head.get()); head.subscribe(() => applyHead(document, head.get()))

Theme:
- Factory: createThemeController({ themes: [lightTheme, darkTheme], defaultThemeId: "light", … }) — NEVER createTheme()
- Presets: import { lightTheme, darkTheme } from "@sometic/theme/presets" (or CDN equivalent)
- DOM: applyThemeToElement(document.documentElement, theme.get()); theme.subscribe(...)

createAppShell may bind theme↔head metadata. It does NOT replace applyHead / applyThemeToElement. Controllers own state; apply* owns DOM. Never touch document/window inside reusable createSystem().

@sometic/auth-local default endpoints (mock MUST match unless you set endpoints explicitly):
```
signIn:        /auth/sign-in
register:      /auth/register
refresh:       /auth/refresh
signOut:       /auth/sign-out
session:       /auth/session
passwordReset: /auth/password-reset
```
FORBIDDEN mock rename without provider config: /auth/sign-up instead of /auth/register.
Optional product route GET /me or GET /items is fine for app data AFTER auth; do not confuse with auth-local session probe.

Anonymous GET /auth/session → 401 is EXPECTED. auth-local treats that as null session. Do not “fix” anonymous 401 as a sign-up bug.

Path aliases (A/B/C Vite apps):
- If using `@/` imports: set BOTH tsconfig paths AND vite.config resolve.alias ("@" → path to src). tsconfig alone is not enough.

Storage:
- createSessionStorageAuthStorage("sometic-auth-app") — string key, NOT { key: "…" }

HTTP + shell:
- createHttp({ baseUrl }) naked → createAppShell({ auth, http, query, … }) → use shell.http only (single auth interceptor)
- refetchOnReauth: false unless justified
- Mock access TTL minutes (e.g. 15m), not seconds

Forms:
- handleSubmit validates controller values, not FormData
- A/B: useFormField + value/setValue/onBlur on every field
- C/D: createForm + keep controller values synced on input; never bare name= only
- Do not dispose page-lifetime forms/auth/shell on remount cleanup

Guards:
- isAuthenticatedStatus / auth.isAuthenticated() (refreshing counts)
- A: useRequireAuth(); B/C/D: subscribe + isAuthenticatedStatus

================================================================================
NON-NEGOTIABLE SOMETIC RULES
================================================================================
1. Dependency direction: adapters → app-shell → features → foundation. Cores never import React/Vue.
2. No browser globals at import time.
3. Auth owns session. HTTP owns transport + 401 refresh. Query owns server/cache data. Store owns client UI prefs only.
4. Client can()/policies are UX-only. Authorize privileged APIs on the server (mock OK).
5. Subpath / CDN URLs for the chosen path only.
6. Packages are unstyled. Consumer owns CSS. No Google Fonts CDN inside publishable package code. No telemetry.
7. Do not invent missing custom elements. Do not mention playgrounds, Invoice Desk, or /guide/examples.
8. Public beta: maturity is a label; packages version independently.

================================================================================
SYSTEM WIRING RECIPE
================================================================================
create-system (no DOM):
1. createLocalAuthProvider({ baseUrl }) — endpoints = defaults unless overridden
2. createAuth({ provider, storage: createSessionStorageAuthStorage("sometic-auth-app") })
3. createHttp({ baseUrl }) naked
4. createQueryClient({ defaultOptions: { queries: { retry: false, refetchOnSubscribe: false, staleTime: 60_000 } } })
5. createHeadController(); createThemeController({ themes: [lightTheme, darkTheme], defaultThemeId: "light", darkThemeId: "dark", mode: "light" })
6. createAppShell({ auth, http, query, head, theme, refetchOnReauth: false })
7. return { shell, auth: shell.auth, http: shell.http, query: shell.query, head, theme }

bootstrap (DOM allowed):
- await auth.whenReady()
- applyHead + applyThemeToElement + subscriptions
- A: providers with shell.*; B: Vue equivalents; C: app context + Elements; D1/D2: globals or ESM bindings from CDN
- Page-lifetime singleton; do not dispose on remount cleanup

Route titles: head.set("route:sign-in", { title: "Sign in" }) etc. Never setTitle.
