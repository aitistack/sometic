================================================================================
PRODUCT TO BUILD
================================================================================
Name: Fieldkit Capture
Users: field technicians capturing forms without reliable connectivity, then syncing.
Outcome: Drafted forms + offline mutation queue + conflict resolution on reconnect + query as server truth after sync + auth hydrate when online.

================================================================================
NON-NEGOTIABLE RULES
================================================================================
- @sometic/offline-queue retries TRANSPORT; @sometic/conflict owns merge policy; @sometic/query holds server truth after sync
- @sometic/drafts for in-progress forms (omit secrets)
- @sometic/store persistence for client field state you intentionally keep
- Only enqueue mutations your API can accept idempotently later
- Reconnect order: hydrate auth → flush queue → conflict strategies → invalidate query
- createAppShell; dispose contracts for listeners/in-flight HTTP; document queue durability across reloads
- Large touch targets; high contrast; prefer native inputs
- No Invoice Desk, playgrounds, telemetry; no import-time navigator/window

================================================================================
