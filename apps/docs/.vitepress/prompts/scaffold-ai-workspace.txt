================================================================================
NON-NEGOTIABLE RULES
================================================================================
- Call the model through @sometic/http (usually via your backend proxy). Never put provider API keys in drafts or client store.
- Streaming: implement with fetch + ReadableStream in the app. Abort on dispose / user cancel.
- Messages and threads: @sometic/query. UI chrome (sidebar width, selected model label): @sometic/store.
- Composer drafts: @sometic/drafts with secret omit.
- Failed sends while offline: @sometic/offline-queue (transport retry only; not model semantics).
- createAppShell for auth/http/query/head composition; page-lifetime System (no Strict Mode dispose of create-once refs); pin @sometic versions; unit + e2e.
- Unstyled: you build chat bubbles, markdown rendering, code highlighting.
- No playgrounds, Invoice Desk, telemetry, invented Sometic packages.
