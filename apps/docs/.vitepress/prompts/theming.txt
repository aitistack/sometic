You are implementing theming with Sometic (@sometic/theme).

Rules:
- Behavior-first tokens → CSS variables; Sometic does not ship Tailwind/Bootstrap runtime
- Theme controller produces ThemeSnapshot (mode, theme id, density, direction, contrast, reduced motion)
- applyThemeToElement on documentElement or a scoped subtree
- Consumer CSS reads variables and data-* attributes; publishable @sometic packages stay font-agnostic
- Preference persistence via @sometic/store/persistent (see theme store docs)
- Docs and demo-surface brand fonts (Chakra Petch / Urbanist / JetBrains Mono) are demo-kit only; never ship those from component packages

Docs: https://sometic.aitistack.com/theming/
Scaffold tokens + light/dark switching without locking the app to one CSS framework.
