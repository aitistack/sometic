================================================================================
PRODUCT TO BUILD
================================================================================
Name: Harbor Listings
Users: buyers browse public listings; sellers authenticate to create/edit listings with images.
Outcome: Catalog + listing detail with SEO head tags + seller create/edit forms + upload pipeline + category select/combobox.

================================================================================
NON-NEGOTIABLE RULES
================================================================================
- Public listing pages set @sometic/head (+ head/seo) metadata matching content
- Catalog/results in @sometic/query; seller mutations invalidate keys
- Upload via @sometic/upload; inputs collect files
- Select/Combobox via framework selection adapters (no Combobox CE)
- Seller routes auth-gated; public catalog may be anonymous
- createAppShell for seller session areas; dispose; no import-time globals
- Unstyled card grids; semantic article/link cards; no fake browser chrome
- No Invoice Desk, playgrounds, telemetry, invented payments package
