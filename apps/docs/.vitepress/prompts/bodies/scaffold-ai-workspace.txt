================================================================================
PRODUCT TO BUILD
================================================================================
Name: Loom Chat Workspace
Users: signed-in creators chatting with an assistant across threads.
Outcome: Thread list + conversation view + composer with drafts + offline send queue + query-backed history + per-thread head titles.

================================================================================
NON-NEGOTIABLE RULES
================================================================================
- Call the model through @sometic/http (usually via your backend proxy). Never put provider API keys in drafts or client store.
- Streaming: implement with fetch + ReadableStream in the app. Abort on dispose / user cancel.
- Messages and threads: @sometic/query. UI chrome (sidebar width, selected model label): @sometic/store.
- Composer drafts: @sometic/drafts with secret omit.
- Failed sends while offline: @sometic/offline-queue (transport retry only; not model semantics).
- createAppShell for auth/http/query/head composition; page-lifetime System (no Strict Mode dispose of create-once refs); pin @sometic versions; unit + e2e.
- Unstyled: you build chat bubbles, markdown rendering, code highlighting.
- No playgrounds, Invoice Desk, telemetry, invented Sometic packages.

================================================================================
REQUIRED PACKAGES
================================================================================
@sometic/app-shell, @sometic/auth (+ adapter), @sometic/http, @sometic/query,
@sometic/forms, @sometic/drafts, @sometic/offline-queue, @sometic/store,
@sometic/head, framework field/button/overlay adapters as needed

Optional: @sometic/theme for tokens

DOMAIN STUBS
================================================================================

================================================================================
SCREENS / UX
================================================================================
1. Auth gate
2. Left: thread list (create, rename, delete)
3. Main: message list + streaming assistant indicator
4. Composer: textarea/field, submit, stop generation, draft autosave
5. Offline banner when navigator says offline (read at runtime, not import time)
6. Head title = thread title

================================================================================
WIRING RECIPE
================================================================================
1. App Shell with auth/http/query/head
2. Query keys: ["threads"], ["threads", id, "messages"]
3. sendMessage mutation:
   - optimistic user message in cache OR local pending row
   - http stream to proxy; append assistant tokens to cache
   - on network failure while offline: enqueue with offline-queue
4. On reconnect: flush queue then invalidate messages
5. Drafts: bind composer text; restore on thread switch
6. dispose aborts active streams

================================================================================
IMPLEMENTATION STEPS
================================================================================
1. Scaffold app + mock proxy that can stream a fake completion
2. System bootstrap + auth
3. Thread list query + mutations
4. Conversation query + renderer (plain text OK; markdown optional via your lib)
5. Composer with drafts + validation (non-empty)
6. Streaming path + Stop button (AbortController)
7. Offline queue path with banner + retry
8. Head titles + consumer chat CSS
9. README: warn “no @sometic/ai”, document proxy env var, abort/dispose behavior

================================================================================
ACCEPTANCE CRITERIA
================================================================================
[ ] Create thread, send message, see assistant stub response
[ ] Streaming can be cancelled mid-flight
[ ] Draft persists when switching away and back
[ ] Going offline queues a send; reconnect flushes
[ ] Secrets never appear in drafts/localStorage dumps
[ ] Query holds history; store only chrome
[ ] No invented Sometic AI package in package.json
