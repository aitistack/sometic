================================================================================
PRODUCT TO BUILD
================================================================================
Name: Launchpad Onboarding
Users: new workspaces completing a checklist; operators enabling modules gradually via flags.
Outcome: Multi-step onboarding forms, prefs checklist progress, feature-flag gates, command palette actions, App Shell bootstrap without flashing gated modules.

================================================================================
NON-NEGOTIABLE RULES
================================================================================
- Flags gate UX; billing entitlements still from backend/auth — never trust client store alone
- Checklist progress in @sometic/store prefs (unless server owns completion)
- Commands via createCommandRegistry + command palette structure adapter
- Resolve flags BEFORE rendering gated routes (or show neutral shell)
- createAppShell; dispose; no import-time globals
- Unstyled friendly empty states in consumer CSS
- No Invoice Desk, playgrounds, telemetry

================================================================================
REQUIRED PACKAGES
================================================================================
@sometic/feature-flags, @sometic/commands, @sometic/forms, @sometic/app-shell,
@sometic/store, @sometic/auth, @sometic/http, @sometic/head,
framework /structure (Command palette), /field

================================================================================
REPO LAYOUT
================================================================================
src/
  system/create-system.ts
  flags/definitions.ts
  flags/bootstrap.ts            // load remote overrides then evaluate
  onboarding/
    steps.ts
    wizard.tsx
  commands/register.ts
  routes/
    home.tsx
    billing.tsx                 // flagged
    team.tsx                    // flagged
  styles/launchpad.css
  mocks/api.ts
README.md

================================================================================
DOMAIN STUBS
================================================================================
Flag keys: "billing", "teamSeats", "betaImporter"
OnboardingStep: { id, title, completed }
WorkspacePrefs: { onboardingStepId, checklist: Record<string, boolean> }

API:
- GET /flags
- GET/PUT /me/prefs
- auth endpoints

================================================================================
SCREENS
================================================================================
1. Sign-in / create workspace
2. Onboarding wizard (3+ steps) with forms validation
3. Home with checklist remaining items
4. Gated routes: Billing/Team hidden when flags off
5. Command palette: “Continue onboarding”, “Open billing” (only if enabled), “Sign out”

================================================================================
WIRING RECIPE
================================================================================
1. Fetch flag payload; createFeatureFlagController({ definitions, remote })
2. createAppShell({ auth, http, query?, head, stores, forms })
3. register commands; bind palette
4. Wizard writes prefs store + optional server prefs
5. Route guards: if (!flags.isEnabled("billing")) redirect
6. Avoid gated flash: delay outlet until bootstrap flags ready

================================================================================
IMPLEMENTATION STEPS
================================================================================
1. Vite + mocks for flags/prefs
2. System + flag bootstrap gate
3. Wizard steps UI (compose; no Stepper package)
4. Prefs persistence
5. Flagged routes + nav
6. Commands + palette
7. README: flag vs entitlement, remote config options

================================================================================
ACCEPTANCE CRITERIA
================================================================================
[ ] With billing flag false, /billing redirects and nav hides
[ ] Checklist progress survives reload (prefs)
[ ] Palette action list respects flags
[ ] No gated module flash on cold load
[ ] Server entitlement note documented even when flag true
