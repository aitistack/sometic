# Installation

Install only the packages you need from the `@sometic` scope.

## Installation

::: code-group

```bash [npm]
npm install @sometic/core
```

```bash [pnpm]
pnpm add @sometic/core
```

```bash [yarn]
yarn add @sometic/core
```

```bash [bun]
bun add @sometic/core
```

:::
