# Validation API

Primary exports:

- Issues: `createIssue`, `ok`, `fail`, `mergeResults`
- Paths: `parsePath`, `getAt`, `setAt`, `deleteAt`
- Validators: `required`, `email`, `minLength`, `maxLength`, `pattern`, `min`, `max`, `integer`, `oneOf`, `custom`, `runValidators`
- Compose: `pipe`, `all`, `any`, `when`, `refine`, `transform`
- Schema contract: `SchemaAdapter`, `assertSchemaAdapter`
- Async helper: `debouncePromise`
