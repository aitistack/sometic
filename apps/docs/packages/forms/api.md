# Forms API

- `createForm`, register, setValue, validateField/Form, handleSubmit, reset, server errors, subscribe, dispose
- Feedback (default on), `feedback` option, `getFeedback` / `setFeedback` / `clearFeedback`
- `createFieldArray`, append/remove/move/swap/replace
- `createDraftController` + memory/localStorage storages
- `createFormSteps`, dynamic step field defs + step field subsets
- `valuesToFormData` / `formDataToValues`
- `announceFormErrors` / `focusFirstInvalid`
