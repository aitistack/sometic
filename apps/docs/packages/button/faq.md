# Button, FAQ

Loading disables press. Icon buttons need `aria-label`.

**Light DOM is the default.** Add the `shadow` attribute for isolated embeds; page CSS will not reach the inner `<button>` unless you inject styles into the shadow root or rely on inherited CSS variables.

Prefer subpath imports for budgets. `registerButtonElements(registry?)` is idempotent. Use `sometic-async-button` with an `.action` function for pending/error events.
